2. `2_spec.md`: alcance funcional y no funcional.

## Regla de trabajo

El codigo debe seguir la especificacion y mantener separacion por capas:

- Controllers: entrada/salida HTTP.
- Servicios: reglas de negocio.
- Repositorios: persistencia.
